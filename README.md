# 🌲 Гостиница «ЛЕС» — Woodo 3D Web Game

Интерактивная трехмерная диорама и тактильная головоломка в стиле **Woodo**, воспроизводящая атмосферу уютной загородной гостиницы «ЛЕС». 

Проект полностью оптимизирован для работы в современных веб-браузерах на **ПК, Mac, iOS (iPhone/iPad) и Android**, а также готов к моментальной публикации на **GitHub Pages**.

---

## 🌟 Особенности проекта

- **4 детализированные фото-локации гостиницы**:
  - 🌲 **Экстерьер и сад**: баварский фасад с клинкерным кирпичом, фахверком, резным балконом, фирменной металлической вывеской «ЛЕС ГОСТИНИЦА», патио и стройными туями.
  - 🛋️ **Гостиная Woodo**: акцентная стена из состаренного кирпича, 3 зеркала на кожаных ремнях, сдвижная амбарная дверь, королевский велюровый диван, кофейный столик Nero Marquina и хрустальная люстра.
  - 🛎️ **Стойка Ресепшен**: деревянная брусовая стойка, кашпо с суккулентами, табло «ВЫХОД» и ключница.
  - 🪑 **Зона ожидания**: дизайнерское панно в технике золотого Кинцуги, геометрическая золотая консоль и мягкие кресла.
- **Тактильная головоломка Woodo (10 предметов)**:
  - Деревянный обеденный стул на 4 ножках, Лягушонок Бен, Лисичка Фокси, Котёнок, медовый горшочек, чайная пара, ложечка, яблочко и кекс.
  - **Умная система ореолов (Ghost Silhouettes)**: активный предмет подсвечивается теплым янтарным сиянием, остальные силуэты приглушены. Лягушонок появляется только после установки стула.
- **Мобильное и сенсорное управление (Touch Optimized)**:
  - **Tap-to-Place**: выбор детали в лотке и короткий тап по силуэту на диораме.
  - **Tap-to-Select**: тап по силуэту на 3D-столике выбирает нужную фигурку в лотке.
  - **Блокировка вращения камеры при drag-and-drop**: сцена не улетает из-под пальцев при сборке.
  - **PWA-режим**: игра устанавливается на домашний экран смартфона как нативное приложение.
- **Аудио-атмосфера**: встроенный эмбиент-саундтрек с ненавязчивым управлением.

## 🚀 Быстрый запуск локально

Для запуска не требуются Node.js или внешние сборщики:
```bash
# Перейдите в папку проекта
cd browser_game

# Запустите локальный HTTP-сервер (Python 3)
python server.py
# или
python -m http.server 8085
```
Откройте в браузере: **`http://localhost:8085`**

## 🌐 Публикация на GitHub Pages

### Способ 1: Автоматический деплой через GitHub Actions (Рекомендуемый)
1. Создайте новый репозиторий на [GitHub](https://github.com/new).
2. Загрузите файлы проекта:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Hotel LES Woodo 3D Game"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git push -u origin main
   ```
3. В репозитории на GitHub перейдите в **Settings** ➔ **Pages**:
   - В разделе **Build and deployment** ➔ **Source** выберите **GitHub Actions**.
4. Включенный в проект workflow `.github/workflows/deploy.yml` автоматически соберет и опубликует игру.
5. Ваша игра доступна по адресу: `https://<ВАШ_ЛОГИН>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/`!

### Способ 2: Классический деплой из ветки (Deploy from a branch)
1. В **Settings** ➔ **Pages** выберите **Deploy from a branch**.
2. Укажите ветку `main` (или `master`) и папку `/(root)`.
3. Нажмите **Save**. Через 1–2 минуты страница станет доступна.

> [!TIP]
> Файл `.nojekyll` уже включен в корень проекта, поэтому 3D-модели `.obj` и текстуры отдаются мгновенно без фильтрации Jekyll.

## 📁 Структура проекта

```
browser_game/
├── index.html            # Главная HTML-страница (PWA-метатеги, оверлей)
├── style.css             # Адаптивные стили для десктопа и смартфонов
├── game.js               # Полный 3D-движок (Three.js, диорамы, логика сборки)
├── manifest.json         # PWA-манифест для установки на мобильные
├── favicon.png           # Иконка сайта и ярлык PWA
├── 404.html              # Страница 404 с редиректом
├── .nojekyll             # Флаг для GitHub Pages (отключает Jekyll)
├── .gitignore            # Исключение временных скриншотов отладки
├── README.md             # Документация проекта
├── libs/                 # Three.js r128, OrbitControls, OBJLoader, Confetti
│   ├── three.min.js
│   ├── OrbitControls.js
│   ├── OBJLoader.js
│   └── canvas-confetti.min.js
├── assets/
│   ├── models/           # 3D-модели фигурок (.obj)
│   ├── textures/         # Текстуры дерева и элементов
│   └── audio/            # Фоновый саундтрек (.mp3)
├── dist/                 # Изолированная продакшн-сборка
└── build.py              # Скрипт сборки в dist/
```

## 🎮 Управление
- **Вращение камеры**: зажать ЛКМ / проведите пальцем по экрану.
- **Приближение**: колесико мыши / жест pinch-to-zoom (сведение двух пальцев).
- **Сборка пазла**: 
  - Нажмите на фигурку в нижнем лотке, затем тапните по подсвеченному золотом силуэту на столике (Tap-to-Place).
  - Либо перетащите фигурку мышью прямо на столик (Drag-and-Drop).
